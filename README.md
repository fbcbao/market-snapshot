# DSH 社区插件目录 · 本地快照

## 这是什么

DSH 的「社区插件市场」自己没有数据，它实时去拉第三方目录源。你这台机器上只启用了一个源：

```
https://deepseek1024.com/api/v2/plugins   （Cloudflare 后面，大陆直连时快时停）
```

这个目录就是趁它偶尔能通的窗口抓下来的本地副本，用来**离线浏览/搜索**，绕开市场 UI 的转圈和失败。

## 怎么用

双击 `index.html` 即可（纯本地，无需联网、无需服务器）。

- 搜索：名字 / 作者 / 中英文描述
- 分类筛选、按安装数 / Star / 最近更新排序
- 「只看可直接安装」= 只保留 npm 包形式的条目
- 「复制安装命令」复制的是目录里给的原始命令

## 安装时的两个坑

1. **目录里的命令写的是 `--profile web`**，你的桌面 Profile 是 `desktop`。
   要自己装就把参数改成 `--profile desktop`，例如：

   ```
   dsh plugin --profile desktop add @liustack/modlens
   ```

2. 目录只给「包名/仓库」，不代表已审核。安装即是以你的权限运行本地代码，
   `github:` 形式的条目尤其要看一眼仓库。

## 想补全全量目录

上游恢复后（或换到有代理的网络）在本目录执行：

```bash
python fetch.py     # 断点续传，只抓 raw/ 里缺的页
python build.py     # 重新生成 plugins.json / data.js / index.html
```

`fetch.py` 会轮换 4 条路由（2 个 IPv4 + 2 个 IPv6 Cloudflare 边缘）、每页最多重试 10 次、
抓到一页存一页，中断后重跑不会重抓。

## 文件说明

| 文件 | 用途 |
|---|---|
| `index.html` | 离线浏览界面 |
| `data.js` | 界面用的数据（`window.DSH_MARKET`） |
| `plugins.json` | 同样的数据，标准 JSON，方便脚本处理 |
| `raw/page-NNNN.json` | 上游原始响应，抓取缓存 |
| `fetch.py` / `build.py` | 抓取 / 生成脚本 |
